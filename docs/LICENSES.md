# ライセンスと配布について

## このリポジトリ

- **ツール (gtl の共通部分・スクリプト・ドキュメント)**: [MIT License](../LICENSE)
- **訳文 (`games/<game>/<言語>.tsv`)・用語集・話者設定・手修正**: ゲームの文章の翻訳 (二次的著作物) で、
  元のゲームの権利者の権利が及ぶ。このリポジトリには入れない (使う人が非公開のデータ用リポジトリに保存する)。
  訳文を公開・配布したい場合は、ゲームごとに権利者の Mod・ファン翻訳に関する方針を確かめること

## 入れていないもの (ゲーム由来のデータ)

次のものはゲームの著作物そのもの、またはそれを含むので、リポジトリにも Mod の配布物にも入れない。
使う人が自分の持っているゲームから作る。

| もの | 理由 |
|---|---|
| 原文入りの翻訳結果 (`*.jsonl`) | ゲームの文章を含む |
| ゲームから取り出したファイル (テキスト・翻訳リソース・アセットなど) | ゲームのデータ |
| ゲームのデータを書き換えたファイル (アーカイブ・パッチ・データファイルなど) | ゲームのデータを含む。ゲームに同梱されている公式訳を使う場合も同じ |
| ゲームの用語の一覧 (検索語のリストなど) | ゲームのデータから抜き出したもの |

Mod を単体で配布する場合も、配布物は自分で作ったもの (プラグイン・フック・手順など) にとどめ、ゲームのファイルを含めない。

## 実行時に取得するもの (同梱しない)

| もの | ライセンス | 使う場所 |
|---|---|---|
| [PLaMo 3 Translate 8B](https://huggingface.co/pfnet/plamo-3-translate-8b-GGUF) (翻訳モデル) | [PLaMo Community License](https://plamo.preferredai.jp/info/plamo-community-license-ja) (個人・非商用は無料、商用は別途契約) | `models/` |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) (翻訳サーバー) | MIT | `compose.yaml` |
| Claude API / OpenAI API | 各サービスの利用規約 | `gtl.yaml` で選んだ場合 |

ゲーム固有の拡張で使うもの (Mod ローダー、フォント、ゲームエンジン、ライブラリなど) は、拡張ごとにライセンスを確かめる。
Mod に同梱して配布するときは、それぞれのライセンス文書も一緒に入れる。

## 同梱しているもの

| もの | ライセンス |
|---|---|
| Go のライブラリ (`go.mod`) | 各ライブラリのライセンス (MIT, BSD, Apache-2.0 など) |

## ほかの人の訳を使うとき

既存のファン翻訳・コミュニティ翻訳を流用・参考にする場合は、ライセンス文を `games/<game>/LICENSE-*.txt` に置き、
組み立てた Mod にも同梱する。あわせて、拡張の説明 (データ用リポジトリ) に次を書く。

- 出典 (URL、作者、版)
- ライセンス (例: MIT なら著作権表示を残す)
- どこに使ったか (用語集だけ、一部の行、全文 など)

ライセンスが書かれていない訳は、作者の許可が無い限り使わない。

## 機械翻訳について

訳文の多くは機械翻訳 (PLaMo 3 Translate、または設定した LLM) で、人が確認・修正した行は `reviewed` になっている。
誤訳があり得ることを Mod の説明に書く。
